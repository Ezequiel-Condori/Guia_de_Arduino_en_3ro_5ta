Consigna:

Realizar un programa que titile 2 leds al mismo tiempo y vaya acelerando el efecto mientras la velocidad permita ver el el efecto y luego vaya reduciendo paulatinamente la velocidad hasta llegar a la velocidad inicial y luego empiece de vuelta

Ver el circuito usado 

//Esta actividad sigue la misma logica que la anterior, pero añadimos un "intermediario" para que podamos identificar cuando tiene que aumentar y bajar la velocidad
int tiempo=1000;   //La variable tiempo de toda la vida
int dir=0;   //El intermediario, su funcion es: si este vale 0, significa que el tiempo es mayor a 50, pero menor a 1000, haciendo que no se pase de ese limite, permitiendo restar el tiempo, pero si vale 1, significa que es menor a 50, cambiando su sentido a sumar el tiempo 

void setup(){
  pinMode(2, OUTPUT);
  pinMode(3, OUTPUT);
}
void loop(){
  digitalWrite(2, HIGH);
  digitalWrite(3, HIGH);
  delay(tiempo);
  digitalWrite(2, LOW);
  digitalWrite(3, LOW);
  delay(tiempo);
  if(dir==0){   //Acá se pregunta si dir vale 0
    tiempo=tiempo-30;   //Si es asi, el tiempo estara decreciendo
  }
  else{   //Y si no vale 0...
    tiempo=tiempo+30;   //El tiempo en lugar de disminuir, va a incrementarse, haciendo que los led titilen mas lentos
  }
  if(tiempo>=1000){   //Acá se pregunta sobre el valor de tiempo, decirmos ¿Tiempo vale mas de 1000?
    dir=0;  //Si la respuesta es si, dir sera 0, osea, va a ir decreciendo hasta que...
  }
  if(tiempo<=50){  //Hasta que sea menor a 50, esa es la pregunta de esta linea, y si es asi...
    dir=1;  //Se cambiara dir a 1, lo que va a hacer que el tiempo vaya incrementandose hasta superar 1000, y asi infinitamente...
  }
}
