EXPLICACIÓN 1: LO FUNDAMENTAL DE ARDUINO

Hola lector/a!!! En esta explicación hablaremos de las líneas MÁS importantes que siempre encontrará en un código de Arduino: void setup() y void loop().
Para explicar su funcionamiento de la forma más sencilla posible, usaremos el código de la actividad 1 del TP1:


void setup(){
  pinMode(2, OUTPUT);      //Configuramos al pin 2 como salida
}
void loop(){
  digitalWrite(2, HIGH);   //Esto prende al LED
  delay(800);              //Le damos un tiempo para apreciar el parpadeo
  digitalWrite(2, LOW);    //Luego de ese tiempo le cortamos corriente, dándonos así el efecto de apagado
  delay(800);              //Este último delay para apreciar al LED mientras está apagado
}

En la primera línea encontraremos al void setup(). Todo lo que pongamos en él se ejecutará PRIMERO (una sola vez), y luego pasará al void loop().
El void loop() sería un bucle infinito que nunca terminará hasta apagar el Arduino. Mi profe Javier Blanco (y yo a veces) le decimos "bucle loop" para no decir "void" a cada rato.
