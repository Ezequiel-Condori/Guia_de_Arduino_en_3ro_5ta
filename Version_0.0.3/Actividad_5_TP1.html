Consigna:

Realizar un programa que titile 2 leds alternativamente acelerando la frecuencia de encendido hasta el momento que no se vea el efecto
y luego vuelva a la velocidad de 1seg de tiempo

Ver el circuito usado 

//Este codigo es CASI lo mismo al anterior, lo que cambia es que el tiempo va decreciendo, y es nuestra primera vez que usaremos Variables y Condicionales
int tiempo=1000;          //Aqui ponemos nuestra variable tiempo

void setup(){
  pinMode(2, OUTPUT);
  pinMode(3, OUTPUT);
}
void loop(){
  digitalWrite(2, HIGH);
  digitalWrite(3, LOW);
  delay(tiempo);          //En los delay, adentro donde va el valor ponemos el nombre de nuestra variable, asi le indicamos al programa que espere elvalor de nuestra variable
  digitalWrite(2, LOW);
  digitalWrite(3, HIGH);
  delay(tiempo);
  tiempo=tiempo-50;        //Aqui pedimos que reste el valor de nuestra variable tiempo de 50 en 50
  if(tiempo<=50){       //Acá preguntamos si tiempo es MENOR o IGUAL a 50, asi nos aseguramos que no baje de 0
    tiempo=1000;           //Si la respuesta es si, hacemos que tiempo vuelva a valer 1000 ms (1 segundo)
  }                        //la parte de if la dejamos vacia ya que queremos que se repita sin cambios
}
