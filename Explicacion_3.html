EXPLICACIÓN 3: VARIABLES Y CONDICIONALES BASICAS

Hola nuevamente lector/a!!! En esta explicación hablaremos de: Las variables y condicionales basicas. Basicas porque hablaremos de las mas simples y menos complejas.
Para explicarlo, usaremos el codigo de la actividad 5:


//Este codigo es CASI lo mismo al anterior, lo que cambia es que el tiempo va decreciendo, y es nuestra primera vez que usaremos Variables y Condicionales
int tiempo=1000;          //Aqui ponemos nuestra variable tiempo

void setup(){
  pinMode(2, OUTPUT);
  pinMode(3, OUTPUT);
}
void loop(){
  digitalWrite(2, HIGH);
  digitalWrite(3, LOW);
  delay(tiempo);          //En los delay, adentro donde va el valor ponemos el nombre de nuestra variable, asi le indicamos al programa que espere elvalor de nuestra variable
  digitalWrite(2, LOW);
  digitalWrite(3, HIGH);
  delay(tiempo);
  tiempo=tiempo-50;        //Aqui pedimos que reste el valor de nuestra variable tiempo de 50 en 50
  if(tiempo<=50){       //Acá preguntamos si tiempo es MENOR o IGUAL a 50, asi nos aseguramos que no baje de 0
    tiempo=1000;           //Si la respuesta es si, hacemos que tiempo vuelva a valer 1000 ms (1 segundo)
  }                        //la parte de if la dejamos vacia ya que queremos que se repita sin cambios
}

Como se indica en los comentarios de dicho código, aquí introducimos las variables y Condicionales.

Las variables son como "Una caja", en la cual podemos llenar de valores, simbolos, letras, etc... Esta se crea con un int [nombre a eleccion]=[letra o valor a eleccion]. Estos, por lo general se ejecutan al inico, esos son conocidos como Variables Globales, pero en ciertos casos se ejecutan adentro del loop (A esos se los conoce como Variables locales). Existen mas tipos de variables, como el long int, y mas... pero eso sera para mas adelante, falta... algo (no mucho), este seria el mas común de todos, y uno de los mas livianos si hablamos de ocupacion de memoria RAM (Aunque eso por ahora no importa tanto). Aquí abajo tiene una lista de lo que consume cada tipo de variable:

  • char= 1 byte ----- Se usa para poner caracteres, como '2', 'b', etc, no son valores y SIEMPRE se tienen que poner entre comillas simples, osea estas: ''.
  • int= 2 bytes ----- Se usa para números enteros del -32768 al 32767, mas alla de eso no soporta.
  • long int= 3-4 bytes ----- Es como un int pero con mayor capacidad, desde -2147483648 al 2147483648.
  • float= 4 bytes ----- Se usa para números decimales o con ".".

En nuestro caso, es solo para números normales, por eso usamos int, se puede usar long int pero ocuparia mas memoria RAM, aunque ahora no importa tanto, mas adelante esto sera importante.

Ahora vamos con las condicionales y su funcionamiento:

Las condicionales son preguntas que hacemos al codigo, por ejemplo, digamos que estamos en un juego, y tienes que usar una llave para pasar a la siguiente parte, el juego vera si tienes la llave o no, si tienes la llave, te dejara continuar (if), pero si no la tienes, el juego va a revisar si te compraste un pase de temporada (else if), pero si ni tienes eso, no te dejara pasar(else). Eso mismo hace el if. Tomemos de ejemplo nuestro if del codigo de arriba, nos dice "Si tiempo es menor a 50, cambia su valor a 1000, en este caso no existe un else (SINO), porque queremos que el codigo funcione normalmente si no se cumple la condicion.

En resumen, if es la pregunta, else if es la siguiente pregunta, y else ocurre si ninguno de los 2 anteriores ocurrio antes. Se pueden poner tantas veces quieras los if y else if, PERO recuerda, solo puede haber un else por cada if que tengas, si por algun motivo pones 2 else y un solo if, te va a tirar error.
