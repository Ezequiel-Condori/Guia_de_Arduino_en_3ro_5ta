0.0.1: El primer paso

Hola!!! Bienvenido a la primer version publicada en GitHub Pages. Esta pagina web esta en una version muy temprana, en la cual solo cuenta con menús, y nada mas.

Pronto se piensa añadir mas cosas, como un diseño, poner mis conocimientos a este sitio, osea... completar la Guia.

Originalmente, solo iban a ser unos archivos de texto en el cual se explique como funciona el codigo del Arduino, el cual solo yo podria leerlo, suena raro, y lo es!, pero luego me dije "Y si esto lo uso como una Guia para cualquier alumno de la Escuela Tecnica Confederación Suiza que quiera elegir computacion como la carrera a futuro?" Y asi fue como este proyecto evoluciono a una carpeta con muchos Archivos .INO, PDF's, y mas, a ser una pagina web simple en la cual se pueda entrar las 24hs del día. Llendo al tema principal, ¿Qué incluye esta version? Bueno, en esta version estan algunos menús, selecctivos, y cosas simples, sin informacion aun, pero va progresando.

Pronto va a recibir una actualizacion, quizas mañana, ¿U hoy? Quien sabe, lo vere... Nos vemos!!!
